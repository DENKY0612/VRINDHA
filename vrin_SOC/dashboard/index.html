🕉️ Dharma Engine - core/dharma_engine.py + intent_analyzer.py

Ethical reasoning layer inspired by Bhagavad Gita - AI Decision = Technical Logic + Ethical Check (Gita-based). Before executing any action, AI should ask: Is this action aligned with Dharma? From Gita: Act with duty (Dharma), Avoid harmful intent, Control ego and misuse of power, Protect others and society
🕉️ Dharma Engine

Purpose: Evaluate whether action ethical before execution

Function: evaluate_action(command, intent) -> decision allow/deny/warn, reason, risk_level low/medium/high, gita_verse, educational

Adharma: unauthorized access, exploitation, data theft, personal gain, revenge, hack this website, steal, bypass security without permission, ddos, deface → DENY + Gita teaching

Dharma: security testing, learning, defense, protect, audit my system, vulnerability assessment, authorized, educational, my network, lab → ALLOW + performing duty aligned with protection

High-risk tools: metasploit, hashcat, hydra, john, burpsuite, exploit, sqlmap → WARN + require justification + Gita self-control teaching

🔍 Intent Analyzer

Suspicious: hack, steal, bypass, crack, exploit, unauthorized, break into, deface, ransom, blackmail

Malicious: steal data, hack this website without, ddos, destroy, delete database, ransomware

Safe: test, learn, secure, protect, audit, my system, defensive, educational, authorized, my network, lab, vulnerability assessment

Logic: Malicious first → malicious, Suspicious + No Safe → suspicious, Suspicious + Safe → safe with note educational context overrides, Safe → safe high confidence, Default neutral → safe low
